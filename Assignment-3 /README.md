# Assignment 3 - Greedy & Dynamic Programming

This assignment contains solutions for two problems using Greedy and Dynamic Programming techniques.

## Problems

### Problem 1 - Scholarship Distribution
**Technique:** Greedy  
Sort scholarship requirements and select the smallest requirements first.

**Complexity:** `O(N log N)` time, `O(N)` space.

### Problem 2 - Maximum Learning Points
**Technique:** Dynamic Programming  
Choose the maximum points while never selecting two consecutive topics.

**Complexity:** `O(N)` time, `O(1)` extra space.

## Language
C++17
